# Smart Parking Management System

## Project Overview

The Smart Parking Management System (SPMS) is a database-driven solution designed to improve parking management by automating parking slot management, bookings, payments, parking passes, EV charging, sensor integration, and dynamic pricing.

## Key Features

- Parking zone and slot management
- User and vehicle management
- Parking slot booking
- Payment tracking
- Parking pass management
- EV charging station and session management
- Dynamic pricing
- Sensor device and sensor log management
- User reviews
- Database-level integrity and validation
- Prevention of double booking

## Database Design

The project uses a relational database designed with normalized entities, primary keys, foreign keys, constraints, and database triggers to maintain data integrity.

## Technologies

- MySQL
- SQL
- Relational Database Design
- ER Modeling
- Database Normalization
- SQL Queries
- Database Triggers
- Transactions
